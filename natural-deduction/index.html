Proving Arguments

June 26, 2025

Consider the following simple argument:

If it is raining I take an umbrella It is raining Therefore, I take an umbrella

Is this argument correct? How can we be sure? In natural language we can construct reasons why this argument must be correct, although it is easy for these reasons to be restatements of the argument. In formal logic, we have mathematical tools to help us. There are several ways in which we can prove that this argument is correct, or more specifically that it is valid as we have no way to verify the truth or otherwise of the premises of the argument.We will first consider how to use truth tables to prove the correctness of an argument. Then, we will introduce a technique called natural deduction that more closely resembles mathematics to help us.

Proof by Truth Table¶

Let us consider how to “prove” our simple argument using a truth table:

If it is raining I take an umbrella It is raining Therefore, I take an umbrella

Using an obvious notation, we can express this as

R  ⟹  UR\implies UR⟹U, RRR, ∴U\therefore U∴U

This is obvious, but can we prove it beyond any doubt. One way to do this is to construct the truth table:

RRRUUUR  ⟹  UR\implies UR⟹U
FFT
FTT
TFF
TTT

We need to ask two questions to prove that the argument is valid:

  • In which row of this table are all of the premises True?

  • Is the conclusion also True on that row?

If the Conclusion is True when all of the premises are True, then the argument is Valid.

Looking at the table, we see that in the fourth row of the table, both of the premises and the conclusion are True and therefore the argument is valid. It iw worth reminding ourselves that if the premises are also True, then the argument would be sound as well.

Consider now the argument

R  ⟹  UR\implies UR⟹U, RRR, ∴¬U\therefore \lnot U∴¬U

The truth table for this is

RRRUUUR  ⟹  UR\implies UR⟹U¬U\lnot U¬U
FFTT
FTTF
TFFT
TTTF

There is no entry in this table in which the two premises and the conclusion are all True and so this argument is invalid (the premises do not support the conclusion).

We can construct a truth table for any argument and use the truth table to prove its correctness. This is extremely rigourous and is also very easy to automate. What it is not, however, is practical for anything but small problems: an argument involving NNN atomic propositions has 2N2^N2N rows in its truth table. This very quickly becomes extremely slow to compute and very memory intensive for even modestly sized systems.

We will therefore explore a different proof technique known as natural deduction. This approach is much more similar to what we would recognise as a “mathematical proof” and is much more easily transferrable to other forms of logic such as first order logic which we will move on to study. It is also more suitable for studying systems with many premises as we do not need to enumerate all of of the possibilities explicitly.

Natural Deduction¶

Natural deduction involves application of so-called inference rules to the premises of an argument. The rules manipulate the premises in ways that are provably correct to create new statements. If the premises are True, and the rules have been applied correctly, then the consequents must also be True. We use the inference rules to perform substitions into the premises until we have arrived at the conclusion (or contradicted it), just as we do when constructing a mathematical proof. Here’s an example of how we do this. Consider the following argument (using symbols previously defined for Raining, Outdoors, Coat):

¬(R∧O)  ⟹  ¬C\lnot(R\land O)\implies\lnot C¬(R∧O)⟹¬C
CCC
OOO
∴R\therefore R∴R

(What is this argument in “English”? Does it makes sense?)

We can prove this argument via the following set of steps:

¬(R∧O)  ⟹  ¬C, C, O : R\lnot(R\land O)\implies\lnot C,\ C,\ O\ :\ R¬(R∧O)⟹¬C, C, O : R

Let us explain some features of the proof

  • Each line of the proof consists of a single proposition.

  • A proposition is either a premise or results from an application of exactly one rule of inference to one or more other propositions.

  • When a rule of inference is applied, the propositions to which it has been applied should be stated as a subscript. For example, the application of Modus Tollens in line 4 uses propositions 1 and 2, whilst the double negation in line 5 uses proposition 4.

  • The premises on which a proposition depends should be listed in the final column, regardless of whether they have been used directly in the application of a rule. For examples, line 5 does not use premises 1 and 2 directly, but they were used to derive premise 4, which does use them directly.

In sequent form, we write this as

¬(R∧O)  ⟹  ¬C, C, O ⊢R\lnot(R\land O)\implies\lnot C,\ C,\ O\ \vdash R¬(R∧O)⟹¬C, C, O ⊢R

Notice that this is subtly different to the outcome of a truth table-based argument, by the use of ⊢\vdash⊢ instead of ⊨\vDash⊨. This denotes that the argument has been shown to be syntactically correct by virtue of having been derived using a set of logical inference rules that have themselves been verified as sematically correct. The overall argument itself has not been explicitly shown to be sematically correct which is what a truth table does and this form of proof is sometimes regarded as weaker than more explicit semantic proofs. It is, nevertheless, widely accepted as a valid form of proof.

This proof of RRR by natural deduction uses only the premises of the argument and some established valid rules of inference. Examples of common inference rules include

We can therefore write

P  ⟹  Q∧R, ¬R, P  ⟺  S, ⊢¬SP\implies Q\land R,\ \lnot R,\ P\iff S,\ \vdash \lnot SP⟹Q∧R, ¬R, P⟺S, ⊢¬S

Notice how, at stage 3, we have used ∧\land∧-introduction by noticing that if RRR is False, then Q∧RQ\land RQ∧R must also be False irrespective of QQQ.

Proofs can also be used to show that arguments are invalid. Two ways to do this are:

  1. By showing the the negation of the conclusion is true. For example, if the argument concludes QQQ but you are able to show that ¬Q\lnot Q¬Q is True, then the argument must be invalid.

  2. By deriving a contradiction. If an argument concludes QQQ and you are able to prove that both QQQ and ¬Q\lnot Q¬Q are True, then the argument must be invalid.
