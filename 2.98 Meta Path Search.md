# Inference with Meta Path Search and Degree-Weighted Path Counting

One of the most important uses of knowledge graphs is in identifying potential relationships that are not explicitly represented in the graph. Sometimes, as in the example shown below, this is a definitive rule. However, in most cases we will not be able to be quite so certain that a new relationship derived in this way will hold.

![An Inference Rule on a Graph](figures/SimpleInferenceRule.png)

The stereotypical example of this is in drug repurposing. A drug can treat a disease by acting on a protein implicated in that disease.  We may therefore be tempted to infer that the drug can be used to treat any disease in which that protein is implicated as illustrated below:

![A Simple Inference Rule for Druf Repurposing](SimpleDrugRepurposing)

This does not tend to work well because our knowledge is *incomplete*. We do not know everything that we would need to know to determine for sure whether the drug will work on other diseases. This is unlike our previous example, where we essentially know everything about the domain of the knowledge graph (University courses). Most knowledge graphs are incomplete and so we will need methods for inference that address this if we wish to use them for inference.

One approach to this is to assess how much *evidence* there is for a new relationship. If drug X treats 10 diseases in which a protein is implicated, then we can be much more confident that it might be used to treat an 11th disease than we would be if it was only known to treat one disease. **Metapath search** is one such technique for assessing the evidence.
