  1. Using the following notation translate the following sentences into predicate notation. For person xxx:

  • C(x)C(x)C(x): xxx is a computer scientist

  • L(x)L(x)L(x): xxx is logical

  • I(x)I(x)I(x): xxx is Irish

a) Some people are logical.
b) All computer scientists are logical.
c) Some Irish people are computer scientists.
d) Some logical people are Irish computer scientists.
e) All Irish computer scientists are logical but not all Irish people are Computer Scientists.
f) Some logical people are not computer scientists.
g) Not all Irish people are computer scientists.
h) There are no computer scientists who are not logical.

Solutions

a) ∃ x [L(x)]\exists\ x\ [L(x)]∃ x [L(x)]
b) ∀ x [C(x)  ⟹  L(x)]\forall\ x\ [C(x)\implies L(x)]∀ x [C(x)⟹L(x)]
c) ∃ x [I(x)∧C(x)]\exists\ x\ [I(x)\land C(x)]∃ x [I(x)∧C(x)]
d) ∃ x [L(x)∧I(x)∧C(x)]\exists\ x\ [L(x)\land I(x)\land C(x)]∃ x [L(x)∧I(x)∧C(x)]
e) ∀ x [I(x)∧C(x)  ⟹  L(x)] ∧ ¬∀ x [I(x)  ⟹  C(x)]\forall\ x\ [I(x)\land C(x) \implies L(x)]\ \land\ \lnot\forall\ x\ [I(x)\implies C(x)]∀ x [I(x)∧C(x)⟹L(x)] ∧ ¬∀ x [I(x)⟹C(x)]
f) ∃ x [L(x)∧¬C(x)]\exists\ x\ [L(x)\land \lnot C(x)]∃ x [L(x)∧¬C(x)]
g) ¬∀ x [I(x)  ⟹  C(x)]\lnot\forall\ x\ [I(x)\implies C(x)]¬∀ x [I(x)⟹C(x)]
h) ¬∃ x [C(x)∧¬L(x)]\lnot\exists\ x\ [C(x)\land \lnot L(x)]¬∃ x [C(x)∧¬L(x)]

  1. Using the following notation and the quantifier specified for each problem, translate the following sentences into predicate notation. For person xxx:

  • C(x)C(x)C(x): xxx is a computer scientist

  • L(x)L(x)L(x): xxx is logical

  • I(x)I(x)I(x): xxx is Irish

a) Some people are logical (∀\forall∀).
b) All computer scientists are logical (∃\exists∃).
c) Some Irish people are computer scientists (∀\forall∀).
d) Some logical people are Irish computer scientists (∀\forall∀).
e) All Irish computer scientists are logical but not all Irish people are Computer Scientists(∃\exists∃).
f) Some logical people are not computer scientists (∀\forall∀).

c) ¬∀ x [¬(I(x)  ⟹  C(x))]\lnot\forall\ x\ [\lnot(I(x)\implies C(x))]¬∀ x [¬(I(x)⟹C(x))]
d) ¬∀ x [¬(L(x)∧I(x)∧C(x))]\lnot\forall\ x\ [\lnot(L(x)\land I(x)\land C(x))]¬∀ x [¬(L(x)∧I(x)∧C(x))]

g) ∃ x [¬(I(x)∧C(x))]\exists\ x\ [\lnot(I(x)\land C(x))]∃ x [¬(I(x)∧C(x))]

Building on the example knowledge base developed in the lectures, write rules to infer the following: a) TakesModule(s,m)\mathrm{TakesModule}(s,m)TakesModule(s,m): student sss studies module mmm b) TeachesOn(p,m)\mathrm{TeachesOn}(p,m)TeachesOn(p,m): Professor ppp teaches on course ccc c) Graduates(s,c)\mathrm{Graduates}(s,c)Graduates(s,c): if student sss has passed all required modules on course ccc then they graduate d) OutstandingRequirementss,m\mathrm{OutstandingRequirements}{s,m}OutstandingRequirementss,m: Student sss has not yet passed a module mmm required by their course

  1. Are the following arguments are valid or invalid. Informal arguments are sufficient.

a) ∀(x)[P(x)] : ∀(x)[P(x)∧Q(x)])\forall(x) [P(x)]\ :\ \forall(x) [P(x)\land Q(x)])∀(x)[P(x)] : ∀(x)[P(x)∧Q(x)])
b) ∃(x)[¬P(x)∧Q(x)] : ∀(x)[P(x)∨Q(x)]\exists(x) [\lnot P(x)\land Q(x)]\ :\ \forall (x) [P(x)\lor Q(x)]∃(x)[¬P(x)∧Q(x)] : ∀(x)[P(x)∨Q(x)]
c) ∀(x)[P(x)∨Q(x)] : ∃(x)[Q(x)]\forall(x) [P(x)\lor Q(x)]\ :\ \exists(x) [Q(x)]∀(x)[P(x)∨Q(x)] : ∃(x)[Q(x)]
d) ∃(x)[¬Q(x)] : ∃(x)[L(x)]\exists(x) [\lnot Q(x)]\ :\ \exists(x) [L(x)]∃(x)[¬Q(x)] : ∃(x)[L(x)]
e) ∀(x)[P(x)] : ¬∃(x)[¬P(x)]\forall(x) [P(x)]\ :\ \lnot\exists(x)[\lnot P(x)]∀(x)[P(x)] : ¬∃(x)[¬P(x)]

Solutions

a) This is a valid argument, by ∨\lor∨-elimination. b) This is invalid. We cannot conclude anything about what is true ∀(x)\forall(x)∀(x) from this premise.
c) This is invalid. The premise could be true if ∀(x)[P(x)]\forall(x)[P(x)]∀(x)[P(x)] and we cannot make this conclusion about Q(x)Q(x)Q(x).
d) This is invalid. ∃(x)[¬Q(x)]\exists(x) [\lnot Q(x)]∃(x)[¬Q(x)] is true if ∀(x)[¬Q(x)]\forall(x) [\lnot Q(x)]∀(x)[¬Q(x)], which would not invalidate the conclusion.
e) This is valid. If P(x)P(x)P(x) is true for all xxx, then there cannot be an xxx for which P(x)P(x)P(x) is false.

  1. The following argument is incorrect.

  • ∃x[P(x)], ∃x[Q(x)] : ∃x[P(x)∧Q(x)]\exists x [P(x)],\ \exists x [Q(x)]\ :\ \exists x [P(x)\land Q(x)]∃x[P(x)], ∃x[Q(x)] : ∃x[P(x)∧Q(x)]

Identify the error in the following proof:

StepRule
1.∃x[P(x)]\exists x [P(x)]∃x[P(x)]Premise
2.P(a)P(a)P(a)∃\exists∃-elimination on (1)
3.∃x[Q(x)]\exists x [Q(x)]∃x[Q(x)]Premise
4.Q(a)Q(a)Q(a)∃\exists∃-elimination on (3)
5.P(a)∧Q(a)P(a)\land Q(a)P(a)∧Q(a)∧\land∧-introduction on (2,4)
6.∃x[P(x)∧Q(x)]\exists x [P(x)\land Q(x)]∃x[P(x)∧Q(x)]∃\exists∃-introduction on (5)

Solution

In steps (2) and (4) we have inferred that PPP and QQQ are true for particular instances by ∃\exists∃-elimination. The mistake is that we have inferred that the same instance is true for both PPP and QQQ. This would be valid of one of these had derived by > ∀\forall∀-elimination but not when both have come from ∃\exists∃-elimination because we cannot determine that the same instances will be True for the two predicates PPP and QQQ.
