# First Order Logic

## Introduction

We have been studying propositional logic which has allowed us to reason over a set of sentences which can each be evaluated as being True or False. 

> All computer scientists are logical
> Alan is a computer scientist
> Therefore Alan is logical

Each of these sentences is a proposition: they can all be evaluated as True of False. Can we prove this argument using propositional logic? Our arguments might be something like

> If a person is a computer scientist then they are logical.
> Alan is a computer scientist.
> Therefore Alan is Logical.

Or, using obvious notation,

> $C\implies L,\ A\implies C,\ A\ :\ L$

This argument seems to stand up, but the definition of the atomic propositions $A$, $C$, and $L$ is rather important here. We might define
 - $C$: The person is a computer scientist
 - $A$: The person is called Alan
 - $L$: The person is logical

This seems rather inelegant and clumsy. Most importantly, if we also decided that we wanted to check whether Niamh and Chen were logical, we would have to construct separate proofs for them. If we also decided that Physicists and Philosophers were all logical as well, then we have a combinatorial explosion of arguments to prove. Propositional Logic becomes even more convoluted if you consider an argument such as:

> All computer scientists are logical
> Some computer scientists are Irish
> Therefore, some computer scientists are logical and Irish.

This argument includes *quantifiers* (all, some) that we do not have natural mechanisms for working with in propositional logic. We circumvented this in the previous argument by careful definitions of the sentences but we cannot apply that trick here because our propositions have to be unconditionally True or False. This makes it difficult to construct generic arguments, or to construct sentences that are conditionally dependent on some variable. First order logic extends propositional logic to include mechanisms for reasoning over statements that include *variables* (Alan), *quantifiers* (all/some), and *predicates* which are propositions with conditions. For this reason we will sometimes refer to the system of logic we are about to describe as **predicate calculus**.

To represent this knowledge using only propositional logic would be impossible complicated. As we have seen with some of the exercises, we would effectively need a separate proposition for every single piece of information. First order logic allows us to represent the problem in an abstract way.

## Variables
Denoted as $x$, $y$, $z$, etc. These allow the same logical expression to refer to different entities. Every variable has a *domain* which described the allowed values of the variable in the context in which it is being used.

In our example, we might define a variable $x$ to be on the domain of *people*.

## Predicates
Predicates are statements that are similar to proposition, but for which their Truth depends on the value of an associated variable or variables. For example $P(x)$: "x is a Greek Philosopher" is true when $x$ is "Socrates" and is False when $x$ is "Donald Trump".

We could chosoe to define the following predicates for our simple example:

* $\mathrm{IsComputerScientist}(x)$
* $\mathrm{IsIrish}(x)$
* $\mathrm{IsLogical}(x)$

where in all three cases, the variable $x$ is defined on the domain of people.

Predicates can be associated with multiple variables (ie $P(x,y)$). Predicates with one argument are called *unary* predicates, those with two arguments are called *binary* predicates. In general, predicates with $n$ arguments are called $n$-ary predicates. Those with zero arguments are referred to as *nullary* predicates, or simply as *propositions*!

## Quantifiers

First order logic also allows us to make general statements about domains. So far we have made statements that apply to individual values of the variables, but there will be instances in which we want to make more general statements that apply to multiple values of a variable. Consider:

- Socrates is a man
- All men are mortal
- Therefore Socrates is mortal

It is quite easy to see that the first premise could be expressed using first order logic as

- Man(Socrates)

and the conclusion as 

- Mortal(Socrates)

How do we represent the second premise? We need some way of specifying that a predicate is True for all values of its variable.

### The Universal Quantifier

* $\forall$, meaning 'for all' (universal quantifier)

Our statement "All computer scientists are logical" is can then be written as

* $\forall\ x\in\{\mathrm{People}\}\ [IsComputerScientist(x)\implies IsLogical(x)]$

Read literally, this states that "if person $x$ is a computer scientist then $x$ is logical for all people". Notice that we use implication here to allow for the possibility of logical people who are not philosophers. What would the following expression mean?

* $\forall\ x\in\{\mathrm{People}\}\ [IsComputerScientist(x)\land IsLogical(x)]$

### The Existential Quantifier

The second common quantifier is

> $\exists$, meaning 'exists' (existential quantifier)

We may therefore write "some computer scientists are Irish" as

* $\exists\ x\in\{\mathrm{People}\}\ [IsComputerScientist(x)\and IsIrish(x)]$

This can be read as "There is at least one person who is both a Computer Scientist and Irish". We may have been tempted to write:

* $\exists\ x\in\{\mathrm{People}\}\ [IsComputerScientist(x)\implies IsIrish(x)]$

Why does this not expression our intended meaning (think about when the implication is True)?

When using quantifiers, you need to think quite carefully about which logical connectives you should be using. It is not difficult to make mistakes. It can sometime be helpful to think about familiar examples.

We can also use logical connectives with quantifiers. For example,

* $\exists\ x\in\{\mathrm{People}\}\ [IsComputerScientist(x)] \land \lnot\forall  x\in\{\mathrm{People}\} [IsLogical(x)]$

means "some people are computer scientists and not all people are logical".


### Duality of Quantifiers

Consider the following two pairs of statements:

 > $\forall\ x\ [C(x)]\quad\iff\quad\lnot\exists\ x\ [\lnot C(x)]$

 and

 > $\exists\ x\ [C(x)]\quad\iff\quad\lnot\forall\ x\ [\lnot C(x)]$

 Are these statements True?

What about the following statements?

> $\forall\ x\ [\lnot P(x)]\quad\iff\quad\lnot\exists\ x\ [P(x)]$

and

> $\exists\ x\ [\lnot P(x)]\quad\iff\quad\lnot\forall\ x\ [C(x)]$P

The quantifiers $\forall$ and $\exists$ are said to be **dual** to each other. We can always write statements written using one quantifier in terms of the other. This will be an important tool when constructing proofs in predicate calculus.


## Building and reasning over Knowledge Base with First Order Logic

What does this give us over what we can already do with propositional logic? Economy of representation and a clear structure. It will be helpful to develop a more extensive example to illustates this. Consider the following set of propositions:

* P1: Alice is a Student
* P2: Diana is a Professor
* P3: Diana teaches ECS8050
* P4: Alice is enrolled on the AI Course
* P5: The AI Course require module ECS8050

Consider the question: does Diana advise (ie. teach) Alice? We can easily infer that she does by reading the sentences, but to determine this from a purely symbolic representation we would need an explicit rule that expresses this:

* $P1 \land P2 \land P3 \land P4 \land P5 \implies P6$

where P6: "Diana advises Alice". Given this rule, if all of P1-P5 are true, P6 must also be true (notice that we do not remove the possibility that there is another way in which Diana could advise Alice).

This does the job for this specific case, but *we would need a separate rule for every possible case*. If we want to determine whether Bob is advised by Faye, this rule will not do this. It will not even work if we change ECS8050 to ECS8051. Even for this very simple problem, we need a large number of rules (that are all very similar) to build anything resembling a functional knowledge base.

This is where first order logic shows its hand. Predicates, variables, and quantifiers allow us to write rules that capture multiple cases. Let's build an example. we define a set of predicates to model a simple university program management structure:

| $\mathrm{Professor}(x)$ | $x$ is a Professor |
| $\mathrm{Course}(x)$ | $x$ is a degree Course |
| $\mathrm{Module}(x)$ | $x$ is a course module |
| $\mathrm{Enrolled}(s,p)$ | Student $s$ is enrolled on Course $p$ |
| $\mathrm{Requires}(p,m)$ | Course $p$ requires module $m$ |

So far, we have not gained very much. We could have created propositions that represented each of these facts, and we would have required the same number of sentences to express the same information. The difference comes when we want to derive new knowledge from these facts such, for example, whether a Professor advises a particular student. In propositional logic we have to create separate rules for every possible combination. In first order logic, we need just the one rule:

$$\exists m,c [\mathrm{Professor}(p) \land \mathrm{Student}(s) \land \mathrm{Teaches}(p,m) \land \mathrm{Course}(c) \land \mathrm{Enrolled}(s,c) \land \mathrm{Requires}(c,m) \implies \mathrm{Advises}(p,s)]$$

The "English" translation of this is: if there exist a module m and a course c such that Professor $p$ teaches module $m$, and module $m$ is required is required on course $c$ and student $s$ is enrolled on course $c$, them Professor $p$ advises Student $s$. Notice that the quantifier over $m$ and $p$ is essential here because what we want to determine whether $\mathrm{Advises}(c,s)$, we only need there to be some $m$ and $c$ such that the statement is satisfied.

## Correctness of Arguments in First Order Logic

In the propositional logic we introduced a distinction between the validity and soundness of arguments. The same ideas are applicable in predicate calculus. Arguments that are sound must be both valid (correctly argued) and based on correct premises. Sentences or predicates must be either True or False and this requires them to be grounded in some **domain** and subject to an **interpretation** which governs how a truth value should be assigned to a given statement.

Consider the simple predicate $P(x)$. We cannot know whether this statement is True or False without knowing what $P$ means and what $x$ is. To determine the truth of this sentence, we need to define the interpretation of $P(\cdot)$ and the domain of $x$ - the range allowable values of $x$. We cannot determine the semantics (ie the meaning) of this sentence and therefore its Truth without these. Let us define an interpretation that $P(x)$ is defined as "$x$ has two wheels". If $x$ is defined on the domain "bicycles", then our sentence is True by (bi?) definition.

If we were to change the definition of $P(x)$ to be "$x$ has feathers and wings" but leave the domain unchanged then our sentence is now False. Similary if we were to change only the domain of $x$ to be "birds", then the sentence would be False.

That is, given a set of premises which are true, we will be constructing and proving arguments that lead to True conclusions and are therefore **valid**. Notice that this is independent of the interpretation which affects only the truth of the premises: the truth of the premises affects only whether the argument is sound.

An argument is valid iff the conclusion is True in every possible domain for every possible interpretation in which the Premises are True.

Thus, the argument $P(x)$, $P(x)\implies Q(x)$: $Q(x)$ is valid, and is independent of the truth of any of premises. In any interpretation in which the premises are True, the conclusion must also be True if the argument is valid.

An argument is invalid iff there exists a combination of domain and interpretation in which the premises are True and the conclusion is False. Notice that it only requires one domain/interpretation combination to falsify an argument (though it is very hard to produce examples of this). The argument $P(x)$, $P(x)\implies Q(x)$: $\lnot Q(x)$ is invalid in all domains (at least that I can think of).

Arguments in first order logic are sound if they are valid and if the premises are all True.

## Proofs in First Order Logic

Proofs in First order Logic are very similar to those in propositional logic, except that we now have to worry about how to handle the quantifiers. Four new rules will enable us to do this.

### $\forall$-elimination
The basic idea here is that if a formula is universally quantified, then we can infer a particular instance

> 1. $\forall x [\phi(x)]$
> 2. $\phi(a)$

This is related to $\land$-elimination because $\forall x [\phi(x)] \equiv \phi(a) \land\phi(b)\land\phi(c)\dots$

### $\exists$-introduction
Given a particular instance we can infer an existential quantification

> 1. $\phi(a)$
> 2. $\exists x [\phi(x)]$

This is related to $\lor$-introduction because $\exists x [\phi(x)] \equiv \phi(a) \lor\phi(b)\lor\phi(c)\dots$


### $\forall$-introduction

> 1. $\phi(a)$
> 2. $\forall x [\phi(x)]$

Why can we do this? If $\phi(a)$ is true for some arbitrary $a$, then, if we know nothing at all about $a$ then it must be True for all $a$. We can only do this if we know nothing else about the particular instance $a$ (ie it is not used in any of the premises of the proof).

Let's run through a few simple examples for illustrative purposes. It is **very important** to note that proofs in first order logic can sometimes be very subtle and proof steps that might seem very natural to us would not typically be accepted by the standards of professional logicians. We will highlight a couple of examples of this. Our proofs will not, in some cases, adhere to the very highest standard of proof that would be accepted by a logician. 

One particular point to highlight in advance of these examples is that applying the rules of proof such as $\land$-elimination under a quantifier is considered to be a rather dangerous thing to do. For the simple examples we will look at, this is unlikely to matter but we will typically proceed by eliminating the quantifiers, applying our rule, and then re-introducing the quantifiers. Let's do a simple example:

* $\forall x [P(x)\land Q(x)] : \forall x [P(x)]$

At first glance this appears to be proven straightforwardly by and-elimination. However, this would not usually be accepted as a valid proof strategy by logicians, who would prefer to proceed in the following way:

| Step | | Rule |
|:------|:------|:------|
| 1. | $\forall x [P(x)\land Q(x)]$ | *{Premise}* |
| 2. | $P(a)\land Q(a)$ | *{$\forall$-elimination on (1)}* |
| 3. | $P(a)$ | *{$\land$-elimination on (2)}* |
| 4. | $\forall x [P(x)]$ | *{$\forall$-intro on 3}* |

We can perform this last step because there is nothing known about $a$.

Here's another example that contains a subtlety:

* $\exists x [P(x)],\ \forall x [P(x)\implies Q(x)],\ \forall x [Q(x)\implies R(x)]\ :\ \exists x [R(x)]$

| Step | | Rule |
|:------|:------|:------|
| 1. | $\exists x [P(x)]$ | *{Premise}* |
| 2. | $P(a)$ | *{$\exists$-elimination on (1)}* |
| 3. | $\forall x [P(x)\implies Q(x)]$ | *{Premise}* |
| 4. | $P(a)\implies Q(a)$ | *{$\forall$-elimination on (3)}* |
| 5. | $Q(a)$ | *{Modus tollens (2,4)}* |
| 6. | $\forall x [Q(x)\implies R(x)]$ | *{Premise}* |
| 7. | $Q(a)\implies R(a)$ | *{$\forall$-elimination on (5)}* |
| 8. | $R(a)$ | *{Modus tollens (5,7)}* |
| 9. | $\exists x [R(x)]$ | *{$\exists$-intro on (8)}* |

It might be tempting to construct a similar argument to prove $\forall x [R(x)]$ by replaced the $\exists$-introduction i in step 9 with $\forall$-introduction, but this would not be correct. Why? Do we know something about $a$?

Let's do another example that uses predicates with multiple arguments:

* $(\forall x) (\forall y) [P(x,x)]\ :\ (\exists x) (\exists y) [P(x,y)]$

| Step | | Rule |
|:------|:------|:------|
| 1. | $(\forall x) (\forall y) [P(x,x)]$ | *{Premise}* |
| 2. | $P(a,a)$ | *{$\forall$-elim on (1)}* |
| 3. | $\exists x [P(x,a)]$ | *{$\exists$-intro on 2}* |
| 4. | $(\exists x) (\exists y)  [P(x,y)]$ | *{$\exists$-intro on 3}* |

Notice that when we replace $a$ in step 3, we do not have to replace all instances.
