  1. Consider the following rule based system:

    • i) F  ⟹  DF\implies DF⟹D

    • ii) F  ⟹  GF\implies GF⟹G

    • iii) E  ⟹  DE\implies DE⟹D

    • iv) B  ⟹  EB\implies EB⟹E

    • v) E  ⟹  AE\implies AE⟹A

    • vi) C  ⟹  AC\implies AC⟹A

    • vii) G  ⟹  CG\implies CG⟹C

    • viii) G  ⟹  BG\implies BG⟹B

    • ix) D  ⟹  BD\implies BD⟹B

a) Given FFF, prove EEE by forward and backward chaining. b) Given GGG, prove DDD by forward and backward chaining. c) Given DDD, prove AAA by forward and backward chaining.

Solution

a)

  • Forward chaining

    • Given FFF, by (i) DDD must be True.

    • Given DDD, by (ix) BBB must be True.

    • Given BBB, by (iv) EEE must be True and the proof is complete.

  • Backward Chaining

    • Assume EEE, by (iv) obtain new goal BBB.

    • Goal BBB leads to new goal DDD by (xi).

    • Goal DDD leads to new goal FFF by (i).

    • FFF is known and so the proof is complete.

b)

  • Forward Chaining

    • Given GGG, by (viii) BBB is True.

    • Given BBB, by (iv) EEE is True.

    • Given EEE, by (iii) DDD is True and and the proof is complete.

  • Backward Chaining

    • Assume DDD, obtain new goal EEE by (iii).

    • Goal EEE leads to new goal BBB by (iv).

    • Goal BBB leads to new goal GGG by (xiii).

    • GGG is known and so the proof is complete.

c)

  • Forward Chaining

    • Given DDD, by (ix) BBB is True.

    • Given BBB, by (iv) EEE is True.

    • Given EEE, by (v) AAA is True and the proof is complete.

  • Backward Chaining

    • Assuming AAA, new goal EEE by (v)

    • Assuming EEE, new goal BBB by (iv)

    • Assuming BBB, new goal DDD by (ix)

    • DDD is known and the proof is complete.

  1. Consider the following rule based system:

    • i) D  ⟹  AD\implies AD⟹A

    • ii) D  ⟹  ED\implies ED⟹E

    • iii) E  ⟹  FE\implies FE⟹F

    • iv) D  ⟹  CD\implies CD⟹C

    • v) C  ⟹  FC\implies FC⟹F

    • vi) F  ⟹  BF\implies BF⟹B

    • vii) B  ⟹  CB\implies CB⟹C

    • viii) A  ⟹  GA\implies GA⟹G

    • ix) G  ⟹  BG\implies BG⟹B

a) Given EEE, prove CCC by forward and backward chaining. b) Given GGG, prove FFF by forward and backward chaining. c) Given AAA, prove BBB by forward and backward chaining.

Solution

a)

  • Forward Chaining

    • Given EEE, by (iii) FFF is True.

    • Given FFF, by (vi) BBB is True.

    • Given BBB, by (vii) CCC is True and the proof is complete.

  • Backward Chaining

    • Assume CCC, new goal BBB by (vii).

    • Assume BBB, new goal FFF by (iv).

    • Assume FFF, new goal EEE by (iii).

    • FFF is known and the proof is complete.

b)

  • Forward Chaining

    • Given GGG, by (ix) BBB is True.

    • Given BBB, by (vii) CCC is True.

    • Given CCC, by (v) FFF is True and the proof is complete.

  • Backward Chaining

    • Assume FFF, new goal CCC by (v).

    • Assume CCC, new goal BBB by (vii).

    • Assume BBB, new goal GGG by (ix).

    • GGG is known and the proof is complete.

c) - Given AAA, by (viii) GGG is True. - Given GGG, by (ix) BBB is True and the proof is complete.

  • Backward Chaining

    • Assume BBB, new goal GGG by (ix).

    • Assume GGG, new goal AAA by (viii).

    • AAA is known and the proof is complete.

  1. Consider the following rule based system:

    • i) D  ⟹  BD\implies BD⟹B

    • ii) D  ⟹  GD\implies GD⟹G

    • iii) C  ⟹  GC\implies GC⟹G

    • iv) C  ⟹  AC\implies AC⟹A

    • v) G  ⟹  EG\implies EG⟹E

    • vi) D  ⟹  BD\implies BD⟹B

    • vii) B  ⟹  FB\implies FB⟹F

    • viii) E  ⟹  FE\implies FE⟹F

    • ix) F  ⟹  HF\implies HF⟹H

    • x) E  ⟹  AE\implies AE⟹A

    • xi) A  ⟹  IA\implies IA⟹I

    • xii) H  ⟹  IH\implies IH⟹I

a) Given GGG, prove III by forward and backward chaining. b) Given CCC, prove HHH by forward and backward chaining. c) Given DDD, prove AAA by forward and backward chaining.

Solution

a)

  • Forward Chaining

    • Given GGG, by (v) EEE is True.

    • Given EEE, by (x) AAA is True.

    • Given AAA, by (xi) III is True and the proof is complete.

  • Backward Chaining

    • Assume III, new goal AAA by (xi).

    • Assume AAA, new goal EEE by (x).

    • Assume EEE, new goal GGG by (v).

    • GGG is known and the proof is complete.

b)

  • Forward Chaining

    • Given CCC, by (iii) GGG is True.

    • Given GGG, by (v) EEE is True.

    • Given EEE, by (viii) FFF is True.

    • Given FFF, by (ix) HHH is True and the proof is complete.

  • Backward Chaining

    • Assume HHH, new goal FFF by (ix).

    • Assume FFF, new goal EEE by (viii).

    • Assume EEE, new goal GGG by (v).

    • Assume GGG, new goal CCC by (iii).

    • CCC is known and the proof is complete.

c) - Given DDD, by (ii) GGG is True. - Given GGG, by (v) EEE is True. - Given EEE, by (x) AAA is True and the proof is complete.

  • Backward Chaining

    • Assume AAA, new goal EEE by (x).

    • Assume EEE, new goal GGG by (v).

    • Assume GGG, new goal DDD by (ii).

    • DDD is known and the proof is complete.

  1. Consider the following rule based system:

    • i) F  ⟹  DF\implies DF⟹D

    • ii) F  ⟹  GF\implies GF⟹G

    • iii) E  ⟹  DE\implies DE⟹D

    • iv) B  ⟹  EB\implies EB⟹E

    • v) E  ⟹  AE\implies AE⟹A

    • vi) C  ⟹  AC\implies AC⟹A

    • vii) G  ⟹  CG\implies CG⟹C

    • viii) G  ⟹  BG\implies BG⟹B

    • ix) D  ⟹  BD\implies BD⟹B

Given FFF, prove EEE by forward and backward chaining using both breadth-first and depth-first search. In each of the four cases, write down the order in which nodes are searched assuming that nodes are evaulated in alphabetical order. You may find it helpful to draw out the graphical representation of the rules.

Solution

a)

  • Forward chaining, breadth-first.

    • Start at FFF.

    • Layer 1 nodes are BBB, DDD, GGG. None of them solve the problem so continue.

    • Layer 2 nodes are CCC (from GGG) and EEE (from BBB and DDD).

    • EEE is our goal, and we have reached it via FFF-BBB-DDD-GGG-CCC-EEE.

  • Forward chaining, depth-first.

    • Start at FFF.

    • FFF connects to BBB, DDD, GGG. Search BBB first.

    • BBB does not solve the problem, so search nodes linked from BBB: EEE.

    • EEE is our goal, and we have reached it via FFF-BBB-EEE.

  • Backward chaining, breadth-first.

    • Start at EEE.

    • Layer 1 (nodes connecting into EEE) is AAA, BBB, DDD. None of these solve the problem so continue.

    • Layer 2 nodes are CCC (from AAA), FFF (from BBB, DDD), GGG (from BBB).

    • FFF is known and so we proved our goal via EEE-AAA-BBB-DDD-CCC-FFF.

  • Backward chaining, depth-first.

    • Start at EEE.

    • EEE has incoming edges from AAA, BBB, DDD. Search AAA first.

    • AAA is not known, so search nodes linked to AAA: CCC.

    • CCC is not known, so search nodes linked to CCC: GGG.

    • GGG is not known, so search nodes linked to GGG: FFF.

    • FFF is known and so we proved our goal via EEE-AAA-CCC-GGG-FFF.

  1. Consider the following rule based system:

    • i) D  ⟹  AD\implies AD⟹A

    • ii) D  ⟹  ED\implies ED⟹E

    • iii) E  ⟹  FE\implies FE⟹F

    • iv) D  ⟹  CD\implies CD⟹C

    • v) C  ⟹  FC\implies FC⟹F

    • vi) F  ⟹  BF\implies BF⟹B

    • vii) B  ⟹  CB\implies CB⟹C

    • viii) A  ⟹  GA\implies GA⟹G

    • ix) G  ⟹  BG\implies BG⟹B

Given DDD, prove BBB by forward and backward chaining using both breadth-first and depth-first search. In each of the four cases, write down the order in which nodes are searched assuming that nodes are evaulated in alphabetical order. You may find it helpful to draw out the graphical representation of the rules.

Solution

  • Forward chaining, breadth-first.

    • Start at DDD.

    • Layer 1 nodes are AAA, CCC, EEE. None of them solve the problem so continue.

    • Layer 2 nodes are FFF (from EEE and CCC) and GGG (from AAA). None of them solve the problem so continue.

    • Layer 3 nodes are BBB (from FFF and GGG).

    • BBB is our goal, and we have reached it via DDD-AAA-CCC-EEE-FFF-GGG-BBB.

  • Forward chaining, depth-first.

    • Start at DDD.

    • DDD connects to AAA, CCC, EEE. Search AAA first.

    • AAA does not solve the problem, so search nodes linked from AAA: GGG.

    • GGG does not solve the problem, so search nodes linked from GGG: BBB.

    • BBB is our goal, and we have reached it via DDD-AAA-GGG-BBB.

  • Backward chaining, breadth-first.

    • Start at BBB.

    • Layer 1 (nodes connecting into BBB) is FFF, GGG. None of these solve the problem so continue.

    • Layer 2 nodes are AAA (from GGG), CCC (from FFF), EEE (from FFF). None of these solve the problem so continue.

    • Layer 3 nodes are DDD (from AAA, CCC, EEE).

    • DDD is known and so we proved our goal via BBB-FFF-GGG-AAA-CCC-EEE-DDD.

  • Backward chaining, depth-first.

    • Start at BBB.

    • BBB has incoming edges from FFF, GGG. Search FFF first.

    • FFF is not known, so search nodes linked to FFF: CCC, EEE. Search CCC first.

    • CCC is not known, so search nodes linked to CCC: DDD.

    • DDD is known and so we proved our goal via BBB-FFF-CCC-DDD.

    • vi) D  ⟹  BD\implies BD⟹B

    • viii) E  ⟹  FE\implies FE⟹F

    • x) E  ⟹  AE\implies AE⟹A

    • xii) H  ⟹  IH\implies IH⟹I

In each of the four cases, write down the order in which nodes are searched assuming that nodes are evaulated in alphabetical order. You may find it helpful to draw out the graphical representation of the rules.

Solution

  • Forward chaining, breadth-first.

    • Start at DDD.

    • Layer 1 nodes are BBB, GGG None of them solve the problem so continue.

    • Layer 2 nodes are EEE (from GGG) and FFF (from BBB). None of them solve the problem so continue.

    • Layer 3 nodes are AAA (from EEE) and HHH (from FFF). None of them solve the problem so continue.

    • Layer 4 nodes are III (from AAA and HHH).

    • III is our goal, and we have reached it via DDD-BBB-GGG-EEE-FFF-AAA-HHH-III.

  • Forward chaining, depth-first.

    • Start at DDD.

    • DDD connects to BBB, GGG. Search BBB first.

    • BBB does not solve the problem, so search nodes linked from BBB: FFF.

    • FFF does not solve the problem, so search nodes linked from FFF: HHH.

    • HHH does not solve the problem, so search nodes linked from HHH: III.

    • III is our goal, and we have reached it via DDD-BBB-FFF-HHH-III.

  • Backward chaining, breadth-first.

    • Start at III.

    • Layer 1 (nodes connecting into III) is AAA, HHH. None of these solve the problem so continue.

    • Layer 2 nodes are CCC (from AAA), EEE (from AAA, FFF), FFF (from HHH). None of these solve the problem so continue.

    • Layer 3 nodes are BBB (from FFF), GGG (from EEE). None of these solve the problem so continue.

    • Layer 4 nodes are DDD (from BBB and GGG),

    • DDD is known and so we proved our goal via III-AAA-HHH-CCC-EEE-FFF-BBB-GGG-DDD.

  • Backward chaining, depth-first.

    • Start at IUIUIU.

    • BBB has incoming edges from AAA, HHH. Search AAA first.

    • AAA is not known, so search nodes linked to AAA: CCC, EEE. Search CCC first.

    • CCC is not known and has no incoming edges, so track back to AAA and search next node, EEE

    • EEE is not known, so search nodes linked to EEE: GGG.

    • GGG is not known, so search nodes linked to GGG: CCC, DDD. CCC has already been searched so search $D

    • DDD is known and so we proved our goal via III-AAA-CCC-EEE-GGG-DDD.
