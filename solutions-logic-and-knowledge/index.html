  1. Is the following argument correct? If not, find the logical flaw.

  • If it is Friday, Siobhan always has fish for dinner.

  • It is not Friday.

  • Therefore, Siobhan will not be having fish for dinner.

Solution

This is not a valid argument. We cannot determine from the information given whether Siobhan has fish for dinner on days other than Friday.

  1. Is the following argument correct? If not, find the logical flaw.

  • If you have an MSc in AI then you will get a good job.

  • Declan has a good job.

  • Therefore, Declan has an MSc in AI.

Solution

This argument is false because the first statement does not state that all good jobs required an MSc in AI.

  1. Is the following argument correct? If not, find the logical flaw.

  • If there is a fire then there will be smoke.

  • There is no snoke.

  • Therefore there is no fire.

Solution

This is a correct argument.

  1. Is the following argument correct? If not, find the logical flaw.

  • If it is cold, John wears a coat.

  • John is wearing a coat.

  • Therefore, it is cold.

Solution

This is not a correct argument. John could be wearing a coat for some other reason (eg. rain, wind).

  1. Which of the following statements are equivalent?

  • Kerry carries an umbrella when it is raining.

  • Kerry does not carry an umbrella when it is not raining.

  • Kerry carries an umbrella unless it is not raining.

Solution

The first statement tells us what Kerry does when it is raining (carry an umbrella), but does not tell what she does when it is not raining.

The second statement tells us that Kerry does not an umbrella when it is not raining, but does not say anything about what she does when it is raining. It is therefore not equivalent to statement (a).

The third statement tells us that when it is raining, Kerry carries an umbrella, and that when it is not raining, she does not carry am umbrella.

Therefore, none of the statements are equivalent.

  1. There are three houses in a row. Each of the houses has one pet (Cat, Dog, Hamster) and one car (Ford, Tesla, VW). From the following pieces of information, can you work out which car and pet go with each house?

  2. The house with the Dog owns the Tesla.

  3. The house in the middle does not have a Cat.

  4. The hamster is not owned by the house on the left.

  5. The house with the VW does not have a cat.

  6. The house in the middle does not own the VW.

Solution

From (1) and (4) we know that the house with the VW does not have a dog or a cat, so it must have the hamster. Further, from (3) and (5) we know that this cannot be the left or middle house, and so we have:

  • Right - Hamster - VW From (2) we know that the house in the middle must have the dog, and therefore, from (1) we have

  • Middle - Dog - Tesla Finally, we must, from what is left over, have:

  • Left - Cat - Ford
